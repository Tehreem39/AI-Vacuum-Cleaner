# AI-Vacuum-Cleaner Simulator
An interactive AI-based vacuum cleaner simulator developed using Python and Tkinter.

Project Overview: 
This project is an interactive AI Vacuum Cleaner Simulator developed using Python and Tkinter.
It demonstrates how an intelligent vacuum cleaner can identify dirty rooms and clean them automatically.

Features: 
Graphical user interface using Tkinter.
Two-room environment (Room A and Room B).
Displays dirty and clean room conditions.
Automatic cleaning simulation.
Visual representation of the vacuum cleaner.

Technologies Used: 
Python
Tkinter

How to Run: 
Install Python on your computer.
Download or clone this repository.
Open the project folder.

Run the Python file:
python vacuum_cleaner.py

Learning Objectives: 
Understanding basic AI concepts.
Learning automation and simulation.
Practicing Python GUI development.
